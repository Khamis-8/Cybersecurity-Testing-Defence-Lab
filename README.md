# Cybersecurity-Testing-Defence-Lab
A practical cybersecurity project exploring penetration testing, vulnerability analysis, Linux security and defensive monitoring.
The aim is to understand how vulnerabilities are identified and tested in controlled environments, and how systems can be secured and monitored against potential threats.

**Project Objectives**

**1. Offensive Security – Penetration Testing**

Explore web application security using OWASP Juice Shop.

Practise using Burp Suite Community Edition.

Investigate vulnerabilities such as SQL Injection, Cross-Site Scripting (XSS), authentication weaknesses and access control issues.

Document findings, risks and remediation recommendations.

**2. Defensive Security**

Develop Linux security and hardening skills.

Understand authentication logs and security events.

Detect repeated failed SSH login attempts.

Develop a Java-based authentication log analysis tool.

**Tools and Technologies**

Ubuntu Linux

VirtualBox

Docker

OWASP Juice Shop

Burp Suite Community Edition

Java

GitHub

**Learning Approach**

Practical exercises will be documented with explanations, methodology, evidence, findings and recommended security improvements.

**Scope and Ethics**

All security testing will be conducted within my own isolated lab or on systems where explicit authorisation has been granted.

**Project Status**

Currently setting up the lab environment and developing foundational networking, Linux and web application security skills.
